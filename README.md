# Сжатие графа

Сериализация/десериализация неориентированного взвешенного графа из TSV в компактный бинарный формат.

## Сборка

```
make
```

Требуется только компилятор C++17 (`g++` или `clang++`). Никаких сторонних библиотек: используется исключительно стандартная библиотека (`<algorithm>`, `<stdexcept>`, `<string>`, `<vector>`, `<cstdint>`, `<cstdio>`, `<cstring>`).

## Запуск

```
./run -s -i input.tsv -o graph.bin
./run -d -i graph.bin -o output.tsv
```

## Алгоритм

Файл делится на три независимые секции.

1. **Список вершин.** ID сортируются, хранятся разрывы между соседними, закодированные кодом Голомба (для равномерно разбросанных ID разрывы геометрические, для них Голомб оптимален). Параметр `m` подбирается перебором по реальной стоимости и пишется в заголовок.

2. **Рёбра.** ID заменяются на плотные индексы `0..V-1`, каждое ребро `{i, j}`, `i <= j`, превращается в один номер пары в треугольной нумерации. Полученный возрастающий список сжимается **binary interpolative coding**: сначала пишется медиана блока, она сужает диапазоны для обеих половин, дальше рекурсия. Плотные участки (строки вершин с большой степенью) дешевеют автоматически, без передачи степеней.

3. **Веса.** По одному байту. Измеренная энтропия — 7.99997 бита из 8, сжимать нечего.

## Результаты

| Файл | Исходный | graph.bin | Сжатие | Сериализация | Десериализация |
|---|---|---|---|---|---|
| small_example.tsv | 1.25 МБ | 146 КБ | 8.6× | 0.01 с | 0.01 с |
| large_example.tsv | 154.7 МБ | 22.35 МБ | 6.9× | 1.6 с | 0.7 с |

Однопоточно. Для `large_example.tsv` секции занимают: рёбра 14.14 МБ, список вершин 2.04 МБ, веса 6.17 МБ.

Round-trip проверен на обоих примерах: множества строк совпадают с точностью до перестановки строк и первых двух ID. Отдельно проверены петли, обратный порядок ID в строке, пустой файл и ID на границах `0` и `2^32-1`.
